## 2. Simulator Recovery Attempt

Recovery steps attempted:

```bash
killall Simulator || true
killall CoreSimulatorService || true
xcrun simctl shutdown all
xcrun simctl erase all
xcrun simctl delete unavailable
```

Result:

- `shutdown all`, `erase all`, and `delete unavailable` completed.
- After cleanup, `xcrun simctl list devices available` still failed.
- Failure reproduced:
  - `CoreSimulatorService connection became invalid`
  - `simdiskimaged crashed or is not responding`
  - `Unable to locate device set`

Conclusion:

- Local simulator screenshot evidence remains blocked by environment-level CoreSimulator instability.
- This pass stopped further simulator chasing and moved to approved substitute evidence.
